# Pasta de Arquivos Públicos (Static Assets)

Adicione sua imagem de perfil e o banner aqui nesta pasta para que o site exiba-os corretamente no desenvolvimento e na produção (Vercel / GitHub).

### Renomeie as suas fotos para os seguintes nomes exatos:
1. **Sua foto de perfil:** `photo.jpg`
2. **Seu banner verde personalizado:** `banner.jpg`

Coloque ambas as imagens dentro desta pasta `public` e faça o commit/upload para o seu Github. O site carregará as imagens automaticamente!
